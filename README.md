# 書籍管理アプリ

Laravelを使用して開発した書籍管理アプリケーションです。

書籍情報の管理に加え、コメント投稿や評価機能を備えています。また、ユーザーの権限に応じて利用できる機能を制限し、管理者は書籍やユーザーの管理を行うことができます。

## セットアップ方法

### 1. リポジトリをクローン

```bash
git clone <repository-url>
cd <project-directory>
```

### 2. Composerパッケージをインストール

```bash
composer install
```

### 3. 環境設定ファイルを作成

```bash
cp .env.example .env
```

### 4. アプリケーションキーを生成

```bash
php artisan key:generate
```

### 5. データベースを設定

`.env` ファイルを編集し、使用するデータベースの接続情報を設定してください。

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=your_database
DB_USERNAME=your_username
DB_PASSWORD=your_password
```

### 6. マイグレーションを実行

```bash
php artisan migrate
```

### 7. シーダーを実行

初期データをデータベースに登録します。

```bash
php artisan db:seed
```

### 8. 開発サーバーを起動

```bash
php artisan serve
```

ブラウザで以下のURLにアクセスしてください。

```text
http://127.0.0.1:8000
```

## 認証・権限管理

Laravel Fortifyを使用した認証機能を実装しています。

ユーザーの新規登録は一般公開せず、管理者がユーザーを登録する方式です。

### ユーザー権限

| 権限      | 説明         |
| --------- | ------------ |
| `general` | 一般ユーザー |
| `admin`   | 管理者       |

### アクセス制御

- 未ログインユーザーは認証が必要なページにアクセスできません。
- 一般ユーザーは管理者専用ページにアクセスできません。
- 管理者のみ管理者向け機能を利用できます。
- ユーザー権限に応じて管理者ページへのリンク表示を切り替えています。
